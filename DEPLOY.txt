QUQN V8 FINAL — GITHUB DEPLOYMENT
=================================

1. Open the existing QUQN GitHub repository.
2. Upload/replace ALL files and folders from this package at repository root.
3. Keep this structure:
   index.html
   legal.html
   manager.html
   CNAME
   robots.txt
   sitemap.xml
   assets/
   worker/
4. Commit the changes to main.
5. Wait for GitHub Pages deployment, then hard-refresh https://quqn.eu/.

IMPORTANT
- Do not upload the outer ZIP itself as the website.
- Do not put these files inside an extra subfolder in the repository.
- Existing Cloudflare Worker secrets are NOT contained in this package and do not need to be changed.
